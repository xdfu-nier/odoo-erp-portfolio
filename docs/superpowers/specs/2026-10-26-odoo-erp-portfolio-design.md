# Odoo ERP 作品集设计

用户已确认公开仓库 `odoo-erp-portfolio`，采用进销存首版范围；后续明确要求先创建项目、默认源码开发、所有依赖限定在项目内。

## 开发环境

使用 Odoo 18 社区版、Python 3.12、PostgreSQL。Python 程序、虚拟环境、数据库二进制、数据目录及工具缓存均位于项目内部；数据库仅监听本机独立端口 55432，Odoo 使用 8069。Docker 为后续可选部署方式。

## 首版边界

- 标准模块：销售、采购、库存与开票。
- 自主扩展：金额阈值审批、审批后改单失效、外部订单幂等导入、公司隔离及单据追踪。
- 演示流程：报价提交审批、确认订单、采购收货、部分发货、开票与退款查询。
- 验证：Odoo 真实 ORM 与数据库集成测试，包含审批绕过、重复请求、同号不同载荷与跨公司访问。
- 交付：中文 README、需求来源与映射、演示数据和操作步骤、VS Code 调试、GitHub Actions。

## 数据与安全

公开仓库仅包含自主代码、配置示例及虚构演示数据。真实简历、账号凭据、运行数据及 Odoo 完整源码排除在版本控制外。接口通过 Odoo 已认证用户调用，使用模型权限与全局公司规则限制访问。

## 验收

先完成可启动、可安装扩展模块的项目骨架并上传 GitHub，再按首版范围逐项实现和验证。公开案例引用需实际读取资料后写入来源，来源事实与本作品集自行设计的规则分开记录。
